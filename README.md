# Embodied AI Learning

具身智能学习笔记与实践仓库。

本仓库用于系统整理具身智能所需的数学、机器学习、强化学习、机器人学、感知与仿真知识，并通过小型项目逐步建立从理论到实践的知识体系。

## 学习目标

具身智能关注智能体如何通过身体与环境交互，其基本闭环是：

> 感知环境 → 理解状态 → 规划决策 → 执行动作 → 接收反馈

本仓库的主要目标包括：

- 补全数学、机器学习与深度学习基础
- 理解强化学习和模仿学习的核心方法
- 掌握机器人运动学、动力学、控制与规划基础
- 学习二维视觉、三维感知和多模态模型
- 熟悉常用机器人仿真平台与 Sim-to-Real 方法
- 通过可复现的小项目连接各个知识模块

## 内容组织约定

模块可以根据实际内容逐步扩展：

```text
module/
├── README.md       # 模块目标、路线与内容索引
├── notes/          # 理论笔记
├── examples/       # 最小可运行示例
└── exercises/      # 习题与实现练习
```

- 笔记使用 Markdown 编写，数学公式使用 LaTeX。
- 一个文件聚焦一个主题，并从模块 README 建立入口。
- 示例应尽量小且可独立运行，明确依赖、输入和预期输出。
- 文件和目录使用小写英文及连字符，例如 `policy-gradient.md`。
- 数据集、模型权重和其他大文件不直接提交到仓库。

## 使用方式

```bash
git clone git@github.com:WGZ-W/embodied-ai-learning.git
cd embodied-ai-learning
```

从上方模块索引选择一个主题，再按照模块 README 中的路线学习。当前仓库处于知识框架搭建阶段，暂时没有统一的运行环境；出现公共代码依赖后再补充环境配置。
