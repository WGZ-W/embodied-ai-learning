# 仿真与 Sim-to-Real

本模块整理机器人仿真平台、环境建模和从仿真迁移到真实系统的方法。

## 学习目标

- 理解机器人仿真的基本组成和数值稳定性问题
- 熟悉常用仿真平台及其适用场景
- 能创建环境、加载机器人并接入控制算法
- 理解域随机化、系统辨识和 Sim-to-Real 评估
