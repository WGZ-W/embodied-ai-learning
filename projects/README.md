# 项目实践

本模块用于把数学、学习算法、机器人学、感知和仿真知识组合成可复现的小型项目。

## 项目要求

每个项目至少记录：

- 问题定义与完成标准
- 环境和依赖
- 数据、模型与配置
- 运行步骤
- 结果、失败现象与结论

## 项目目录约定

```text
project-name/
├── README.md       # 目标、运行方法、结果与结论
├── configs/        # 实验配置
├── src/            # 项目代码
└── tests/          # 必要的自动化测试
```

只有项目开始实施时才创建对应目录。
