# 学习资源

本模块集中维护经过筛选的书籍、课程、论文、数据集和工具，避免在不同模块重复收集链接。

## 资源索引

| 类型 | 收录原则 | 状态 |
| --- | --- | --- |
| 书籍 | 优先选择体系完整、适合长期查阅的教材 | 待整理 |
| 课程 | 优先选择有公开讲义、作业或视频的课程 | 待整理 |
| 论文 | 优先收录奠基工作、综述和可复现代表作 | 待整理 |
| 数据集 | 记录任务、规模、许可协议和获取方式 | 待整理 |
| 工具 | 记录用途、官方文档和适用场景 | 待整理 |

## 维护约定

- 每项资源附一句用途说明，而不是只堆积链接。
- 外部链接优先指向官方来源。
- 收录论文时记录题目、年份、任务和代码地址。
- 使用数据集前检查其许可协议和引用要求。
