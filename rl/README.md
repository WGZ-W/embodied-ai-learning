# 强化学习

本模块整理智能体通过环境反馈学习决策策略的方法，并覆盖与具身智能紧密相关的模仿学习和离线强化学习。

## 学习目标

- 理解 MDP、价值函数和 Bellman 方程
- 掌握基于价值与基于策略的经典算法
- 理解 Actor–Critic、离线强化学习和模仿学习
- 能完成算法实现、训练诊断和实验对比
