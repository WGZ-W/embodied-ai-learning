# 强化学习练习与项目

## 一、MDP 与动态规划

1. 为 GridWorld 写出状态、动作、转移、奖励和折扣因子。
2. 手算一个两状态 MDP 的 $V^\pi$ 和 $Q^\pi$。
3. 实现迭代策略评估、策略迭代和价值迭代。
4. 比较不同 $\gamma$ 对策略和收敛速度的影响。

## 二、表格型学习

5. 实现 First-visit MC 与 TD(0)，比较学习曲线方差。
6. 实现 SARSA 与 Q-learning，分析有风险路径上的行为差异。
7. 实现 n-step TD 或 TD($\lambda$)。
8. 比较固定、线性衰减和指数衰减 $\epsilon$。

## 三、DQN

9. 从零实现 Replay Buffer、目标网络和 DQN 更新。
10. 分别移除 Replay Buffer 与目标网络，记录训练稳定性。
11. 实现 Double DQN，比较 Q 过估计。
12. 正确区分 termination 与 truncation，并构造错误实现作对照。

## 四、策略优化

13. 在多臂老虎机上实现 REINFORCE 和 baseline。
14. 手工验证 Gaussian 策略的 log-prob 与梯度形状。
15. 实现 GAE，并与 MC advantage 比较方差。
16. 从零实现最小 PPO，记录 KL、clip fraction、entropy 和 explained variance。

## 五、连续控制

17. 比较 DDPG、TD3 与 SAC 的探索方式。
18. 检查 `tanh` 动作变换和环境缩放的一致性。
19. 对 SAC 温度参数和目标熵做消融。
20. 除 return 外，比较动作平滑度、能耗和约束违反。

## 六、模仿与离线学习

21. 在专家演示上训练行为克隆并分析闭环误差累积。
22. 混合专家与随机数据，观察 BC 表现变化。
23. 比较 BC 与一种保守 Offline RL 方法。
24. 可视化数据集状态—动作覆盖并识别 OOD 动作。

## 七、综合项目

### A. 离散导航

在含障碍和随机转移的 GridWorld 中比较 Value Iteration、Q-learning 与 DQN，报告样本效率、最终成功率和策略鲁棒性。

### B. 连续控制

在一个标准连续控制环境中比较 PPO 与 SAC。统一网络规模和环境步数，运行至少三个随机种子，报告回报、成功率、训练时间和动作平滑度。

### C. 模仿到强化学习

先用演示数据进行行为克隆，再用在线 RL 微调。分析初始性能、样本效率、灾难性遗忘和分布偏移。

## 实验报告要求

- 问题定义、MDP 与成功标准
- 环境版本和 wrapper 顺序
- 算法、网络、超参数与训练预算
- 随机种子与 checkpoint 选择规则
- 学习曲线、汇总统计和消融
- 失败案例、限制和复现步骤

## 完成检查

- [ ] 实现 DQN 或 PPO 中至少一个深度 RL 算法
- [ ] 完成多随机种子比较
- [ ] 正确处理终止与截断
- [ ] 完成至少一个综合项目
