# 感知与多模态

本模块整理智能体理解视觉、深度、点云、语言等观测所需的方法，并关注感知结果如何服务于行动。

## 学习目标

- 掌握图像形成、视觉特征和基础视觉任务
- 理解相机模型、深度估计和三维几何
- 掌握点云表示与处理基础
- 理解视觉语言模型与视觉—语言—动作模型
