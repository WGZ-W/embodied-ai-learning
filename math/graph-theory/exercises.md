# 图论练习

1. 分别用邻接表和邻接矩阵表示同一张图并比较空间开销。
2. 实现 BFS 和 DFS，记录访问顺序与父节点。
3. 使用 BFS 恢复无权网格中的最短路径。
4. 实现 Dijkstra 并解释为什么负边会破坏其正确性。
5. 为四连通与八连通网格设计可采纳的 A* 启发式。
6. 比较 Dijkstra 与不同启发式 A* 的扩展节点数。
7. 实现 Kruskal 或 Prim，并与最短路径树比较。
8. 对任务依赖图进行拓扑排序和环检测。
9. 计算小图的 Laplacian 及其特征值，验证连通分量性质。
10. 把三个位姿与里程计、回环约束画成因子图。

综合题：在带障碍与不同地形代价的二维地图上实现 A*，可视化开放集、关闭集、最终路径和总代价，并分析启发式权重对速度与最优性的影响。
