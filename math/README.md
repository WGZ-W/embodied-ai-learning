# 数学基础

本模块整理具身智能常用的数学工具，重点关注概念、推导及其在感知、决策和控制中的应用。

## 学习目标

- 掌握向量、矩阵、特征值、SVD 与坐标变换
- 理解概率分布、贝叶斯推断与状态估计基础
- 掌握梯度、雅可比、海森矩阵与常用优化方法
- 理解微分方程、数值积分和图搜索的基本方法
