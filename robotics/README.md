# 机器人学

本模块整理机器人建模、状态估计、控制和规划知识，关注算法与真实机器人系统之间的联系。

## 学习目标

- 掌握刚体位姿表示及机器人正逆运动学
- 理解动力学建模与常用控制方法
- 熟悉定位、建图和运动规划基础
- 理解机器人软件系统中的感知—规划—控制接口
