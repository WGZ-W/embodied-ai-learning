# 机器学习与深度学习练习

练习按照“概念检查 → 最小实现 → 综合实验”组织。每次实验都应保存配置、随机种子、学习曲线和结论。

## 一、学习问题与数据

1. 将“预测机械臂抓取是否成功”定义为机器学习任务，明确输入、输出、损失和评估指标。
2. 说明为什么把同一轨迹的相邻帧随机划分到训练集和测试集会导致数据泄漏。
3. 为“在未见物体上泛化”设计按对象划分的数据集方案。
4. 构造一个类别比例为 99:1 的预测结果，展示 Accuracy 与 F1 对模型评价的差异。

## 二、经典监督学习

5. 仅使用 NumPy 实现线性回归的闭式解，并与 `np.linalg.lstsq` 比较。
6. 推导二分类交叉熵对 logit 的梯度。
7. 使用同一份表格数据比较逻辑回归、决策树和随机森林：
   - 使用相同的数据划分。
   - 报告训练与验证指标。
   - 比较模型复杂度和错误样本。
8. 构造一个训练误差和验证误差都很高的实验，再构造一个训练误差低但验证误差高的实验，分别解释原因。

## 三、神经网络与反向传播

9. 手工推导一个输入层、隐藏层和输出层组成的 MLP 的梯度。
10. 仅使用 NumPy 实现两层 MLP，并在一个二维分类数据集上训练。
11. 使用有限差分对第 10 题的梯度进行数值检查。
12. 使用 PyTorch 重写同一模型，对比损失曲线和最终决策边界。
13. 故意移除 `optimizer.zero_grad()`，观察并解释训练行为。

## 四、优化与泛化

14. 在相同初始化下比较 SGD、SGD with Momentum 和 Adam，绘制训练与验证曲线。
15. 对学习率进行数量级搜索，例如 $10^{-4}$、$10^{-3}$、$10^{-2}$、$10^{-1}$，分析收敛速度和稳定性。
16. 让模型过拟合 16 个样本；如果失败，逐项排查数据、损失、梯度和参数更新。
17. 比较无正则化、权重衰减和 Dropout 三种设置，说明它们对训练误差与验证误差的影响。
18. 对同一实验运行至少三个随机种子，报告均值和标准差。

## 五、现代架构

19. 手工计算一个只有两个 token 的单头注意力示例。
20. 使用 PyTorch 实现缩放点积注意力，并检查注意力权重每行之和为 1。
21. 计算不同卷积核、步幅和填充设置下的输出形状。
22. 比较一个小型 CNN 与 MLP 在图像分类任务上的参数量和验证表现。
23. 分别解释 CNN、Transformer 和 Diffusion 中最重要的归纳偏置或建模假设。

## 六、综合实验

### A. 可复现的图像分类基线

选择一个小型公开图像数据集：

1. 固定训练集、验证集和测试集。
2. 建立多数类或随机基线。
3. 训练一个小型 CNN。
4. 记录随机种子、超参数和最佳模型选择规则。
5. 绘制损失与准确率曲线。
6. 输出混淆矩阵并分析至少五个错误样本。
7. 比较有无数据增强的结果。

### B. 机器人状态预测

构造或选择一组机器人时序数据，用过去若干步状态预测下一步状态：

1. 按时间划分数据，避免未来信息泄漏。
2. 建立“复制当前状态”基线。
3. 比较线性模型、MLP 和一种序列模型。
4. 分别报告单步误差与多步滚动误差。
5. 分析分布外运动状态下的失败情况。

### C. 无监督表征评估

选择一组无标签图像或机器人观测：

1. 比较原始像素、PCA 和一个预训练编码器的表示。
2. 使用同一线性分类器进行 Linear Probe。
3. 比较全量标签与少量标签设置。
4. 可视化最近邻样本并解释表示捕获了什么因素。
5. 在光照、背景或视角变化下评估稳定性。

### D. Transformer 序列预测

使用合成序列或传感器时间序列：

1. 实现位置编码、Padding mask 和 Causal mask。
2. 建立线性预测和 RNN 基线。
3. 训练一个小型 Transformer。
4. 比较单步预测与多步滚动预测。
5. 测量序列长度增加时的显存和延迟变化。

### E. 生成式动作建模

构造一个“同一状态对应两种有效动作”的二维数据集：

1. 用 MSE 回归观察平均动作问题。
2. 选择混合密度、VAE 或扩散方法表达多峰分布。
3. 比较负对数似然、样本覆盖和任务成功率。
4. 可视化条件动作分布。
5. 分析采样温度或去噪步数的影响。

## 七、工程与部署检查

24. 保存并恢复模型、优化器和调度器，验证续训后的损失连续性。
25. 比较 `model.train()`、`model.eval()` 与 `torch.inference_mode()` 下的输出和性能。
26. 在目标设备上测量 batch size 为 1 时的 P50、P95 和 P99 延迟。
27. 对模型进行 FP16/BF16 推理，对比精度、延迟和显存。
28. 构造光照、噪声或遮挡扰动，绘制性能随扰动强度变化的曲线。
29. 为模型设计一个包含阈值、拒识和安全动作的回退流程。
