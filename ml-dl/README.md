# 机器学习与深度学习

本模块整理机器学习与深度学习基础，为强化学习、视觉感知和多模态模型建立统一基础。

## 学习目标

- 理解监督学习、自监督学习及常用评估方法
- 掌握神经网络、反向传播和优化基础
- 理解 CNN、Transformer 与生成模型的核心结构
- 能使用 PyTorch 完成基础模型训练与调试
